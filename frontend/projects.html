ACTIVE PLATFORMFIELD NOTE 001

Cloudy Joe

AWS portfolio & private-access platform

A working portfolio that doubles as a cloud engineering lab, with secure content delivery, passwordless sign-in, access approvals, and serverless workflows.

  • S3
  • CloudFront
  • Cognito
  • API Gateway
  • Lambda
  • DynamoDB

What works today

Private S3 origin behind CloudFront; Route 53 DNS and ACM HTTPS; Cognito one-time-passcode sign-in; access requests, administrative approvals, and email notifications backed by API Gateway, Lambda, DynamoDB, and SES.

A challenge worth discussing

Protecting administrative operations required more than hiding the UI. Backend endpoints distinguish anonymous requests, signed-in users without admin privileges, and authorized administrators.

What's next

Infrastructure as Code, automated delivery, and deeper operational observability are future improvements—not features already deployed.

IN DEVELOPMENTFIELD NOTE 002

HomeOps Dashboard

Python homelab tooling

A small home-network dashboard project for practicing Python application structure, Git workflows, environment setup, and incremental development.

  • Python
  • Flask
  • Git
  • GitHub
  • PowerShell

Current foundation

Local Python development environment, a Flask application structure, HTML template, and a Git repository for tracking changes.

A challenge worth discussing

Getting a reproducible Windows development workflow involved virtual environment setup, PowerShell execution policy, repository structure, and Git remote configuration.

What's next

Expand the dashboard with useful home-network status information, tests, and deployment documentation. This project is still in progress.
