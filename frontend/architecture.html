Under the Hood

Platform Architecture

Cloudy Joe is being built as a working cloud engineering portfolio. The architecture evolves in phases so each technology solves a specific problem rather than being added only for demonstration.

Current State

Phase 1 Architecture

Client Web Browser

Renders the frontend and handles local interaction.

→
Application HTML / CSS / JavaScript

Provides the current local application interface.

→
Development Local HTTP Server

Serves the application during local development.

Target Platform

Planned architecture layers

Edge & Delivery

Route 53, CloudFront, TLS certificates, and web application protection.

Identity & Security

Cognito, IAM, authorization rules, audit logging, and least-privilege access.

Application Services

API Gateway, Lambda, DynamoDB, containerized services, and future AI workflows.

Infrastructure as Code

Terraform will manage the primary platform while selected components demonstrate CloudFormation.

Containers

Docker packages application services and ECR stores versioned container images.

Kubernetes

EKS will later demonstrate orchestration, deployments, services, health checks, and scaling.

Engineering Decisions

Architecture Decision Records

Major technical decisions are documented so the reasoning, tradeoffs, and consequences remain visible as the platform evolves.

Accepted

ADR-001: Platform Architecture Strategy

Establishes the phased architecture and the principle that each technology must solve a defined problem.

Proposed

ADR-002: Authentication Strategy

Defines the initial direction for private portfolio access using managed identity and an approval workflow.
