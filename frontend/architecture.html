Under the Hood

Platform Architecture

Cloudy Joe is being developed as a hands-on cloud engineering platform rather than a traditional static resume site. Each phase introduces infrastructure only when it solves a defined technical problem.

AWS Services

What Each Service Solves

Every service in the current architecture has a specific responsibility rather than being included simply to increase the number of technologies used.

Amazon Route 53

Provides DNS for the Cloudy Joe domain and routes production traffic to CloudFront.

Problem solved: domain name resolution and application traffic routing.

Amazon CloudFront

Serves the frontend through AWS edge locations and provides the public delivery layer for the platform.

Problem solved: secure HTTPS delivery, caching, performance, and controlled access to the origin.

AWS Certificate Manager

Provides the TLS certificate used by CloudFront for the custom Cloudy Joe domains.

Problem solved: encrypted HTTPS communication and trusted certificate management.

Amazon S3

Stores the production frontend deployment artifact including HTML, CSS, JavaScript, and images.

Problem solved: durable and inexpensive storage for static application assets.

Origin Access Control

Allows CloudFront to securely retrieve objects from the private S3 bucket using signed requests.

Problem solved: preventing users from bypassing CloudFront and directly accessing the S3 origin.

CloudFront Security Headers

A managed response headers policy adds browser-facing security protections at the CloudFront edge.

Problem solved: improving browser security without requiring the static application to generate headers itself.

Security

Private Origin Architecture

Public Delivery Layer

CloudFront is currently the public-facing entry point for the portfolio.

Visitors retrieve site content through CloudFront, not directly from Amazon S3.

Private Storage Layer

S3 Block Public Access remains enabled and static website hosting is disabled.

Direct anonymous requests to the S3 object URLs are denied.

Least-Privilege Access

The S3 bucket policy grants CloudFront only the permissions necessary to retrieve frontend objects.

Access is restricted to the designated CloudFront distribution.
