Platform Architecture

Cloudy Joe is being built as a hands-on cloud engineering platform rather than a traditional static resume site. Each phase introduces infrastructure only when it solves a defined technical problem.

AWS Services

What Each Service Solves

Every service in the current architecture has a defined responsibility rather than being included simply to add another technology to the stack.

Amazon Route 53

Provides DNS for the custom Cloudy Joe domain and routes application traffic to CloudFront.

Problem solved: domain name resolution and traffic routing.

Amazon CloudFront

Acts as the public delivery layer for the frontend and serves content through AWS edge locations.

Problem solved: HTTPS delivery, CDN caching, performance, and a controlled entry point to the application.

AWS Certificate Manager

Provides the TLS certificate used by CloudFront for cloudy-joe.com and www.cloudy-joe.com.

Problem solved: encrypted HTTPS communication and managed certificate lifecycle.

Amazon S3

Stores the production deployment artifact including HTML, CSS, JavaScript, and static assets.

Problem solved: durable and cost-effective storage for the frontend.

Origin Access Control

Allows CloudFront to securely retrieve objects from the private S3 bucket using signed requests.

Problem solved: preventing users from bypassing CloudFront and directly accessing the S3 origin.

Security Headers

CloudFront applies a managed response headers policy to improve browser-facing security.

Problem solved: adding browser security protections without requiring the static application itself to generate HTTP headers.

Security Model

Private Origin Architecture

CloudFront is the public-facing delivery layer. The S3 bucket itself is not exposed directly to the internet.

Public Delivery Layer

Visitors access the portfolio through CloudFront using the Cloudy Joe custom domain.

Private Storage Layer

S3 Block Public Access remains enabled and S3 static website hosting is disabled.

Anonymous direct requests to S3 objects are denied.

Least-Privilege Access

The S3 bucket policy grants CloudFront only the access required to retrieve frontend objects.

Access is restricted to the designated CloudFront distribution.
